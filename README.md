# انشر — Anshur MVP

منصة عربية للنشر الموحد وإدارة المحتوى. النسخة الحالية MVP تفاعلي مجاني للعرض والاختبار، وليست بعد خدمة نشر Production.

## المنجز
- واجهة عامة RTL بخط Cairo.
- دخول تجريبي محلي ولوحة تحكم.
- إنشاء منشور ومحاكاة النشر الموحد.
- الجدولة وحملات WhatsApp التجريبية.
- الحسابات والتكاملات، بما فيها سلة وزد.
- مكتبة المحتوى والفريق والصلاحيات.
- الباقات والفوترة ومحفظة X المنفصلة.
- التحليلات والإعدادات وحارس الميزانية.
- `app-state.js` كأساس لحالة محلية مشتركة دون Backend مدفوع.

## سياسة التكلفة والأمان
لا تستدعي النسخة الحالية APIs مدفوعة، ولا يجوز وضع مفاتيح API أو access tokens أو كلمات مرور داخل هذا المستودع العام. الخدمات الخارجية تبقى معطلة حتى اعتمادها.

## قبل التشغيل التجاري
1. Backend وقاعدة بيانات آمنة.
2. Auth حقيقي بدل التخزين المحلي.
3. OAuth رسمي لكل منصة.
4. APIs الرسمية ومراجعات التطبيقات المطلوبة.
5. Queue/worker وWebhooks للنشر والجدولة.
6. Secret Manager للأسرار.
7. دفع واشتراكات فعلية.
8. سجلات تدقيق وrate limiting ونسخ احتياطي وسياسات خصوصية وشروط استخدام.

## مبدأ التنفيذ
يتم تجهيز واختبار أكبر قدر ممكن بالأدوات المجانية أولًا. أي خدمة قد تنشئ تكلفة تشغيلية تبقى معطلة حتى اعتمادها صراحة.
