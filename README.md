# انشر — Anshur MVP

منصة عربية للنشر الموحد وإدارة المحتوى.

## الحالة الحالية
نسخة MVP للعرض والاختبار بدون تشغيل خدمات API مدفوعة.

## الصفحات
- `index.html` الموقع العام.
- `login.html` دخول تجريبي محلي.
- `dashboard.html` لوحة التحكم.
- `accounts.html` ربط الحسابات والتكاملات — محاكاة.
- `schedule.html` الجدولة — محاكاة.
- `campaigns.html` حملات WhatsApp — محاكاة.
- `analytics.html` التحليلات التجريبية.
- `billing.html` الباقات والفوترة ومحفظة X التجريبية.

## المنصات المستهدفة
Instagram, Facebook, Threads, LinkedIn, TikTok, X.

## تكاملات التجارة
سلة وزد ضمن الخطة، مع إمكانية استخدامهما كمسار تحصيل أولي قبل بوابة دفع مباشرة.

## قاعدة حماية الميزانية
لا يتم تفعيل API مدفوع، بوابة دفع، WhatsApp Business API، X API، خدمة AI مدفوعة، أو استضافة مدفوعة قبل اختبار الحاجة والموافقة على التكلفة.

## ما يلزم للانتقال من Demo إلى Production
1. Backend وقاعدة بيانات حقيقية.
2. نظام Auth آمن بدل localStorage.
3. OAuth الرسمي لكل منصة.
4. تخزين tokens مشفر وآمن.
5. Queue/worker لعمليات النشر والجدولة.
6. Webhooks لتحديث حالات النشر.
7. تكامل سلة/زد ثم بوابة الدفع المباشرة عند الحاجة.
8. سياسات الخصوصية والشروط والموافقات اللازمة قبل الإطلاق العام.

## ملاحظة أمنية
لا تضع مفاتيح API أو كلمات مرور أو secrets داخل ملفات الواجهة أو المستودع العام.
